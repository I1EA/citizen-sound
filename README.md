# Citizen Sound

**Your city. Your sound. Democracy, amplified.**

Citizen Sound is a democratic platform that gives communities control over their soundscape—turning noise into a collective conversation. It allows citizens to **Boost** or **Mute** street performers in real-time, helping performers thrive and neighbors sleep.

---

## Features

- **Boost / Mute** — Real-time crowd voting on volume
- **Super Boost / Mute** — Paid interactions ($0.99) for a larger volume impact
- **Performer Mode** — Go Live and see live crowd response
- **Map View** — Discover performers near you
- **Emergency Alerts** — Notify performers of nearby issues
- **Leaderboard** — Top performers ranked by community support

---

## Tech Stack

- React Native + Expo
- UI Kitten
- Firebase (Auth + Firestore)
- Google Maps
- react-native-ble-plx (Bluetooth)

## Getting Started

### Prerequisites

- Node.js
- Expo CLI

### Installation

1. **Clone the repo:**
   ```bash
   git clone https://github.com/I1EA/citizen-sound.git
   cd citizen-sound
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up environment variables:**

   Create a `.env` file in the root and add your keys (see `.env.example` if available):
   ```env
   FIREBASE_API_KEY=your_key
   GOOGLE_MAPS_API_KEY=your_key
   ```

4. **Start the app:**
   ```bash
   npx expo start
   ```
